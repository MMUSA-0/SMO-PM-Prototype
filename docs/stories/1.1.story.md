### Scope

**In Scope:**
- Display full Vision 2030 text in bilingual format (Arabic/English)
- Show vision title and formatted content
- Display last update date
- Show progress monitoring dashboard with statistics
- Tab-based navigation between Vision Information sections
- Read-only display of vision content
- Support for RTL/LTR layouts based on selected language

**Out of Scope:**
- Editing vision information (covered in UC-02)
- Managing pillars (covered in UC-02)
- Managing detailed themes (covered in UC-03)
- Advanced analytics and reporting
- Document upload/management (future enhancement)

## Main Success Scenario

1. User logs into the SMO Vision Center system
2. User navigates to "مركز معلومات رؤية 2030" (Vision 2030 Information Center) menu
3. System displays the Vision Information page with default "المعلومات الخاصة بالرؤية" tab active
4. System displays an accordion section titled "لوحة متابعة رؤية المملكة 2030" showing:
   - Overall progress percentage (e.g., 87.3%)
   - Total initiatives count with status breakdown
   - Budget utilization percentage
   - Completed milestones count
   - Latest achievements marquee
5. System displays full Vision 2030 text below the monitoring dashboard
6. System shows Vision 2030 logo and three main pillars:
   - مجتمع حيوي (Vibrant Society)
   - اقتصاد مزدهر (Thriving Economy)
   - وطن طموح (Ambitious Nation)
7. System displays rich text paragraphs describing the vision
8. System shows last update date at the bottom
9. User can switch between tabs: "المعلومات الخاصة بالرؤية", "الركائز", "المحاور التفصيلية", "مؤشرات الاقتصاد الكلي", "المستندات"
10. User can switch language (Arabic ⇄ English) and see RTL/LTR layout changes

### Threat Modeling (STRIDE summary)

**Potential Threats:**
- **Spoofing:** Unauthorized access by spoofed JWT tokens
  - *Mitigation:* Validate JWT signature and expiration
- **Tampering:** Modification of vision text during transmission
  - *Mitigation:* HTTPS only, no client-side editing allowed
- **Information Disclosure:** Unauthorized users accessing vision data
  - *Mitigation:* Role-based authorization checks
- **Denial of Service:** Heavy traffic on vision page
  - *Mitigation:* Caching strategy, CDN for static resources
- **Elevation of Privilege:** Read-only user attempting to edit
  - *Mitigation:* Frontend enforces read-only, backend validates permissions

**State Management:**

```typescript
export class VisionDisplayComponent implements OnInit {
  visionInfo: VisionInformation | null = null;
  dashboard: VisionDashboard | null = null;
  loading = false;
  currentLanguage = 'ar';  // Default Arabic
  currentYear = new Date().getFullYear();

  constructor(
    private visionService: VisionInformationService,
    private translate: TranslateService
  ) {}

  ngOnInit(): void {
    this.loadVisionInfo();
    this.loadDashboard();
  }

  loadVisionInfo(): void {
    this.loading = true;
    this.visionService.getVisionInformation().subscribe({
      next: (data) => {
        this.visionInfo = data;
        this.loading = false;
      },
      error: (err) => {
        console.error('Error loading vision information:', err);
        // Display error message to user
        this.loading = false;
      }
    });
  }

  loadDashboard(): void {
    this.visionService.getDashboardStatistics().subscribe({
      next: (data) => {
        this.dashboard = data;
      },
      error: (err) => {
        console.error('Error loading dashboard statistics:', err);
        // Dashboard can fail gracefully - show "Data not available"
      }
    });
  }

  toggleLanguage(): void {
    this.currentLanguage = this.currentLanguage === 'ar' ? 'en' : 'ar';
    this.translate.use(this.currentLanguage);

    // Update HTML attributes
    document.documentElement.setAttribute('dir', this.currentLanguage === 'ar' ? 'rtl' : 'ltr');
    document.documentElement.setAttribute('lang', this.currentLanguage);

    // Reload data to get translated content
    this.loadVisionInfo();
  }
}
```

### Technical Constraints

1. **No CQRS:** Use single repository for both reads and writes [Source: CLAUDE.md, architecture/9-coding-standards.md]
2. **Controllers inject AppServices only:** Never inject IRepository or IUnitOfWork in controllers [Source: CLAUDE.md]
3. **Use TableNoTracking for read-only:** All read queries should use `disableTracking: true` [Source: CLAUDE.md, architecture/7-data-architecture.md]
4. **Bilingual support mandatory:** All text must support Arabic and English [Source: PRD, BR-003]
5. **RTL/LTR layout switching:** Must dynamically change based on selected language [Source: NFR-008]
6. **Performance targets:** Page load < 2s, statistics calculation < 1s [Source: NFR-001, NFR-002]
7. **Accessibility compliance:** WCAG 2.2 Level AA [Source: NFR-004, NFR-005]
8. **JWT authentication required:** All API endpoints protected [Source: NFR-007, architecture/4-backend-architecture.md]
