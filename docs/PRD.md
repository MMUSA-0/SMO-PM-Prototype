# مقدمة

تهدف هذه الوثيقة إلى توثيق متطلبات
الأعمال الخاصة بمركز معلومات رؤية 2030، النسخة التجريبية المطورة على
بيئة VDP Staging وتُعد هذه الوحدة المكون الأول
والأساسي ضمن المنظومة الرقمية الاستراتيجية للمملكة العربية السعودية،
والمنصة الموحدة لمتابعة تنفيذ رؤية 2030.

# وصف عام للمركز

يمثل مركز معلومات رؤية 2030 المصدر
الرسمي والموثوق لكافة البيانات والمعلومات المتعلقة بالرؤية، ويغطي
المجالات التالية:

- الركائز الثلاث لرؤية
  2030

- المحاور الاستراتيجية

- الأهداف العامة
  والتنفيذية

- البرامج والمبادرات

- مؤشرات الأداء الرئيسية
  (KPIs)

ويهدف المركز إلى تعزيز الشفافية
وتمكين أصحاب القرار من الوصول إلى معلومات موثوقة ومحدثة تدعم المتابعة
الفعالة وصنع القرار.

# الهدف من الوثيقة

تُعد هذه الوثيقة مسودة أولية تتضمن
وصفًا دقيقًا ومفصلًا لمتطلبات الأعمال الخاصة بالمرحلة الحالية من تطوير
المنصة، إلى جانب عدد من التحسينات المقترحة. وقد تم إعداد هذه الوثيقة
لتكون مرجعًا إرشاديًا لفريق التطوير عند تنفيذ المتطلبات ضمن بيئة العمل
التجريبية (Staging Environment) التي تهدف إلى رفع
جودة المخرجات وتحقيق الكفاءة التشغيلية للمشروع، وتجدر الإشارة إلى أن هذه
الوثيقة لا تمثل الصيغة النهائية، حيث إنها خاضعة للتعديل والتحديث وفقًا
لما يستجد خلال مرحلة جمع المتطلبات. وسيتم توثيق جميع التعديلات
والمراجعات عند الانتهاء من استكمال كافة المتطلبات للمشروع، تمهيدًا لإصدار
النسخة النهائية من الوثيقة.

| يجب إعادة حساب نسبة إنجاز المبادرة عند تحديث المعالم |  |
| يجب ربط جميع المعالم بالمخرج |  |
| يتم إنشاء رمز فريد لكل معلم جديد تلقائياً عند الإضافة |  |
| رمز المعلم يجب أن يكون فريد على مستوى جميع المبادرات في النظام |  |
| اسم المعلم يجب أن يكون فريد على مستوى المبادرة |  |
| رمز المخرج المستخدم لربط المعلم يجب أن يكون موجود مسبقاً كرمز أساسي أو مؤقت |  |
| يمكن للمستخدم استخدام خاصية استيراد من ملف اكسل ليتم استيراد جميع المخرجات من الملف كم يمكن للمستخدم تحميل النموذج المستخدم ليتم التعرف عليه من قبل النظام بشكل صحيح. |  |
| يظهر النظام خيار "عرض التفاصيل" للمعلم من تبويب المعالم ليظهر له النظام تفاصيل المعلم للعرض فقط |  |
| يظهر النظام خيار "سجل التغييرات" للمعلم من تبويب المعالم ليظهر له النظام تفاصيل التغيرات التي تمت على هذا المعلم لكل جدول يحتوي على نوع التغيير (إضافة أو تعديل أو حذف)، وقت التغيير والمستخدم والسبب. ويمكن للمستخدم من الاطلاع على تفاصيل الحقول التي تم تعديل ليتم عرض الحقل والقيمة السابقة والقيمة الجديدة |  |
| يتم تضمين التعليمات التالية عند رفع الملفات: |  |
| 1. رفع الملفات: - يتم رفع المعالم والمخرجات في ملفين منفصلين: ملف خاص بالمخرجات وآخر خاص بالمعالم. - يجب رفع ملف المخرجات أولاً قبل رفع ملف المعالم، ولن يسمح النظام برفع المعالم قبل ذلك. - يمكن للمستخدم استخراج ملف المخرجات أو المعالم الخاص بالمبادرة الحالية لتعديله ثم رفعه مرة أخرى. - يتيح النظام تنزيل نماذج فارغة لملفات المخرجات والمعالم لتسهيل ملء البيانات المطلوبة. - في حالات طلبات الدمج أو التقسيم، يمكن استخراج ملفات المخرجات والمعالم للمبادرات القديمة لتعديلها ورفعها ضمن المبادرات الجديدة. |  |
| 2. الرمز المؤقت: - يتم إنشاء رمز مؤقت للمخرجات والمعالم الجديدة فور رفع الملف. - يمكن استخدام الرمز المؤقت للمخرج عند ربط المعالم بالمخرجات. |  |
| 3. قواعد التحقق: - النظام يتحقق من صحة البيانات عند رفع الملفات وفقًا للقواعد التالية: - جميع الرموز يجب أن تكون موجودة مسبقًا في المبادرة الحالية. - الرموز المكررة غير مقبولة. - لا يمكن تعديل رمز مخرج أو معلم موجود في الملف. إذا كان الرمز المدخل غير مطابق للنظام، يعرض النظام رسالة "خطأ في الإدخال" ولن يتم قبول الملف. - يقوم النظام بالتحقق من قواعد العمل الخاصة بإضافة او تعديل او حذف مخرج او معلم مثل ان يكون اسم المعلم او المخرج فريدا على مستوى المبادرة او ان مجموع اوزان المعالم لا تتخطى 100 % وغيرها |  |
| 4. التنبيهات والأخطاء المحتملة: - أي خطأ في الإدخال سيؤدي إلى رفض الملف بالكامل حتى يتم تصحيح الأخطاء. - في حال وجود أخطاء في الإدخال، يعرض النظام ملف يحتوي على تفاصيل الأخطاء، بما في ذلك: - رمز المخرج أو المعلم. - اسم المخرج أو المعلم. - وصف الخطأ الذي أدى إلى رفض الملف. |  |
| 5. تعليمات إعداد البيانات داخل الملفات: - إضافة مخرجات أو معالم جديدة: - يجب ترك حقل الرمز فارغًا. - اختيار العملية "إضافة". - تعديل مخرجات أو معالم: - يجب عدم تعديل حقل الرمز. - اختيار العملية "تعديل". - حذف مخرجات أو معالم: - يجب عدم تعديل حقل الرمز. - اختيار العملية "حذف". - ربط معلم بمخرج جديد: - يجب رفع ملف المخرجات أولاً للحصول على الرمز المؤقت للمخرج، والذي يمكن استخدامه لربط المعلم بالمخرج. |  |
