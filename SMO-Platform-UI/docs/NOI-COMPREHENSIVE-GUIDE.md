## 🔄 آلية Roll-up (Performance Aggregation)

### المعادلة الأساسية
```
أداء الرؤية = Σ(أداء الركيزة × وزن الركيزة)
أداء الركيزة = Σ(أداء البرنامج × وزن البرنامج)
أداء البرنامج = Σ(أداء المبادرة × وزن المبادرة)
أداء المبادرة = Avg(أداء الأنشطة)
```

### مثال عملي:
**برنامج تطوير القطاع المالي:**
- الأنشطة (3) → أداء مجمع: 79.5%
- المبادرات (4) → أداء مجمع: 77.13%
- البرنامج → 77.13%
- الركيزة المالية → 78%
- الرؤية 2030 → 73%

### التأثير المتسلسل (Cascade Effect)
```
تحسن 10% في GDP
    ↓
+8.5% إيرادات حكومية
-3.2% معدل البطالة
+6.5% استثمار أجنبي
+4.8% جودة الحياة
    ↓
+7.3% تأثير نهائي على الرؤية
```

### قوالب الأوزان المعدة مسبقاً
1. **متوازن** - جميع المؤشرات متساوية
2. **اقتصادي** - التركيز على النمو الاقتصادي
3. **اجتماعي** - التركيز على جودة الحياة
4. **حرج** - المؤشرات الحرجة فقط

### توزيع الأوزان الحالي
- **النمو الاقتصادي:** 35%
- **الاستقرار المالي:** 30%
- **جودة الحياة:** 35%

### معادلة الحساب
```
CI = Σ(wi × Ii) / Σwi

حيث:
CI = المؤشر المركب
wi = وزن المؤشر i
Ii = قيمة المؤشر i المطبعة
```
