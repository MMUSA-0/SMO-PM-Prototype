🔧 أداة تطبيق الشريط الجانبي الموحد

📋 تعليمات الاستخدام:
  1. افتح هذه الصفحة في المتصفح
  2. اضغط على "فحص الصفحات" لعرض قائمة الصفحات
  3. راجع التعديلات المطلوبة لكل صفحة
  4. انسخ الكود المطلوب وطبقه على كل صفحة

الملفات المطلوبة للشريط الجانبي الموحد

  • ✅ assets/components/sidebar.html - مكون الشريط الجانبي
  • ✅ assets/js/sidebar-manager.js - مدير الشريط الجانبي
  • ✅ assets/css/sidebar-unified.css - أنماط الشريط الجانبي
  • ✅ assets/js/apply-unified-sidebar.js - سكريبت التطبيق

قائمة الصفحات للتحديث

الكود المطلوب إضافته لكل صفحة

1. في قسم <head> - أضف رابط CSS:
<!-- Unified Sidebar Styles --> <link rel="stylesheet" href="assets/css/sidebar-unified.css">
2. استبدل الشريط الجانبي الحالي بـ:
<!-- Unified Sidebar Container --> <div id="sidebarContainer"> <!-- Sidebar will be loaded here dynamically --> </div>
3. قبل نهاية </body> - أضف السكريبتات:
<!-- Unified Sidebar Manager --> <script src="assets/js/sidebar-manager.js"></script> <!-- Optional: Auto-apply unified sidebar --> <script src="assets/js/apply-unified-sidebar.js"></script>

طريقة سريعة للتطبيق

يمكنك تطبيق الشريط الجانبي الموحد على أي صفحة بإضافة هذا السطر فقط قبل </body>:

<script> // Quick implementation const link = document.createElement('link'); link.rel = 'stylesheet'; link.href = 'assets/css/sidebar-unified.css'; document.head.appendChild(link); const script = document.createElement('script'); script.src = 'assets/js/sidebar-manager.js'; document.body.appendChild(script); </script>

التحقق من التطبيق

بعد التطبيق، افتح وحدة التحكم (Console) في المتصفح وستظهر رسالة:

╔════════════════════════════════════════════╗ ║ Unified Sidebar Implementation Ready ║ ╚════════════════════════════════════════════╝

اختصارات لوحة المفاتيح:

  • Ctrl + B - تبديل الشريط الجانبي
  • Ctrl + K - البحث في القائمة
