⚠️ تنبيه: الأيقونات لا تظهر عند فتح الملفات مباشرة

عند فتح ملفات HTML مباشرة بالضغط المزدوج، قد لا تظهر بعض الأيقونات والصور بسبب قيود الأمان في المتصفح.

✅ الحل: استخدم أحد هذه الخيارات

الخيار 1: استخدام VS Code Live Server (الأفضل)

  1. افتح المشروع في VS Code
  2. ثبت إضافة Live Server
  3. انقر بالزر الأيمن على index.html
  4. اختر "Open with Live Server"

الخيار 2: استخدام Python Server

افتح Command Prompt في مجلد المشروع واكتب:

python -m http.server 8000

ثم افتح: http://localhost:8000

الخيار 3: استخدام Node.js

اكتب في Command Prompt:

npx http-server
